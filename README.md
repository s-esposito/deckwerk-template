# DeckWerk progress-report template

A [DeckWerk](https://github.com/vsitzmann/deckwerk) deck to start progress reports from: seven
example slides (title, last week, image grid with error maps, chart + table, web animation, live
3D viewer, next steps), one palette to restyle them, and rules for people and their coding agents.

    cp -r deckwerk-template <dd-mm-yyyy> && rm -rf <dd-mm-yyyy>/.git

Everything else (workflow, layout, content rules, tools, your own colours) is in
[AGENTS.md](AGENTS.md).
